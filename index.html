TOKEN-ANALYTICS RCLONE

Private-use Google Drive integration for the TOKEN-ANALYTICS research project.

Purpose

This application uses rclone and Google Drive OAuth to back up, retrieve, and verify project files in the account owner's Google Drive.

Google Drive access

The application requests Google Drive permissions for owner-initiated file operations. It is not offered as a public service.

Privacy

Research files and OAuth credentials are not published on this website.
