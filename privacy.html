Privacy Policy

TOKEN-ANALYTICS RCLONE

Effective date: October 11, 2026

1. Purpose

TOKEN-ANALYTICS RCLONE is a private-use Google Drive integration operated by the project owner using the open-source rclone software. It is not a public service.

2. Google Drive access

The application requests permission to view, create, edit and delete Google Drive files. These permissions are used for owner-initiated backups, retrieval, organization and integrity verification of research project files.

3. Data handling

Google Drive data is accessed through rclone running on the owner's device. OAuth credentials are stored locally by rclone. Project files remain under the owner's control in Google Drive and authorized local storage.

4. Data sharing

The application does not sell Google user data or use it for advertising. It does not independently transmit Google Drive file contents to third-party analytics or marketing services.

5. Retention and deletion

The owner determines how long project files are retained. Files may be deleted using Google Drive or rclone. The owner can revoke OAuth access through Google Account security settings.

6. Security

Google Drive access uses OAuth 2.0. Access credentials are not published on this website. The owner is responsible for securing the local device and rclone configuration.

7. Website

This website is hosted on GitHub Pages. It does not intentionally use advertising or analytics trackers. GitHub may process technical access information according to its own privacy policies.

8. Contact

Questions may be directed to the owner through the project GitHub profile.
